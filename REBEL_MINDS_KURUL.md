# Rebel Minds: Cosmos — Yayın Kurulu

This folder is the production office of the faceless YouTube channel **Rebel Minds: Cosmos** (@RebelMindsCosmos). An AI editorial board of subagents (in `.claude/agents/`) researches, writes, reviews, plans visuals and quality-checks every episode. The owner (Tunç) is the editor-in-chief and gives final approval.

## Commands
- `/yeni-bolum <topic>` — script board: research → draft → 3 independent reviewers → revision (max 2 rounds) → strategist → report. Stops for Tunç's approval.
- `/gorsel-kurul <episode-slug>` — visual board: director scene plan → free NASA candidates → image selector → graphic designer → `production.json`.
- `/son-kontrol <episode-slug> [video path]` — director watches sampled frames of the rendered video and reports problems by timestamp.

## Rules for every board member
- Read `kanal/stil_rehberi.md` before doing creative work. It is the channel's style law.
- Scripts are in **English** (target audience). Notes, summaries and reports for Tunç are in **Turkish**.
- Everything is free: no paid APIs. Research uses WebSearch/WebFetch, images come from public-domain/open archives (NASA Image Library; ESA/Webb, ESA/Hubble and ESO are CC BY 4.0 — credit required).
- Every factual claim needs a source. Rebellious but honest: we may challenge consensus, never misrepresent evidence.
- Write outputs ONLY to the paths you are told. JSON files must be valid JSON (no comments, no trailing commas).

## Episode folder layout — `bolumler/<slug>/`
```
research.md            Araştırmacı
script.md              Başyazar (always the latest draft)
script_tur1.md         archived drafts
hakem/<rol>_tur<N>.json   reviewers (dogrulayici, supheci, hikaye)
hakem/geri_bildirim_tur<N>.md   merged feedback (generated by tools/kurul.py)
karar.json             board decision (generated)
strateji.json          YouTube strategist
kurul_raporu.md        report for Tunç (generated)
sahne_plani.json       Yönetmen
adaylar/scene_XXX/     candidate images + meta.json (generated)
secimler/*.json        Görsel Seçici
grafik.json            Grafiker
assets/                final images (generated)
production.json        render package (generated)
gorsel_raporu.md       visual report (generated)
kontrol_kareleri/      sampled frames (generated)
kontrol/*.json         final check notes
son_kontrol_raporu.md  final check report (generated)
```

## Helper tool
`python3 tools/kurul.py <subcommand>` (on Windows, if `python3` is not found, use `py -3` or `python` instead — same arguments) — deterministic glue (scoring, NASA search/download, packaging, frame extraction). Run `python3 tools/kurul.py -h` for help. Board thresholds live in `kanal/ayarlar.json`.
